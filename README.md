# OFDevice device handbook

Public documentation site: https://kushagraof.github.io/OFDevice-Handbook/

Frontend and backend integration handbook, version 1.0, 4 November 2026.

Includes 44 command catalog entries, 103 endpoint entries, sample payloads, WebSocket workflows, Postman requests and TypeScript/React/Python examples.

The site is a static documentation artifact and sends no API requests. The handoff ZIP is available from the page. This repository contains only the handbook and its download files; it contains no backend runtime source or credentials.

GitHub Pages serves the main branch root. .nojekyll disables Jekyll processing.
